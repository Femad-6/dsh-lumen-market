# 流明市场 · Lumen Market

在 DeepSeek Harness 官方「插件」页面发现 npm、GitHub 和已添加安装源中的插件，查看介绍、管理安装与更新。

**版本：0.8.0** · [npm](https://www.npmjs.com/package/dsh-lumen-market) · [GitHub](https://github.com/Femad-6/dsh-lumen-market) · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/Femad-6/dsh-lumen-market/issues)

## 安装与进入

在 Harness 官方「插件 → 添加插件」中输入：

```text
dsh-lumen-market@0.8.0
```

按官方提示完成安装，必要时完全退出并重新启动 Harness。之后从 **插件 → 流明市场** 进入。

0.8.0 已移除重复的独立侧栏入口。请保留 `dsh-lumen-market` 插件本体，官方页面中的市场标签由它提供。

如果镜像尚未同步新版本，可在官方安装窗口使用 npm 官方安装包地址：

```text
https://registry.npmjs.org/dsh-lumen-market/-/dsh-lumen-market-0.8.0.tgz
```

Node.js 要求为 `^22.19.0 || >=24.0.0`。官方页面入口需要宿主支持 `plugins.tab` 扩展；明确声明的 DSH 版本为 `0.2.1-rc.2`，其他版本的验证状态见 [package.json](package.json)。

## 怎么选择安装方式

| 入口 | 行为 | 适用情况 |
| --- | --- | --- |
| **一键安装** | 先调用官方安装接口；明确失败后，按条件自动尝试市场备用源 | 日常安装的首选入口 |
| **通过官方安装** | 将 GitHub 地址或 npm 包交给 Harness 原生安装窗口 | 需要在官方窗口查看诊断、调整来源或处理授权 |
| **安装预览** | 走市场的目标、兼容性与来源查验，确认后安装 | 希望先查看市场解析出的安装目标 |

两个安装按钮底层都使用官方管理器。原生窗口可能便于手动排查，但不能保证解决相同的网络、权限或兼容性问题。

### 一键安装如何回退

```text
点击一键安装
    ↓
官方接口查验并安装 GitHub 地址 / npm 包
    ├─ 成功：结束并刷新列表
    ├─ 确认未改变配置的网络、超时或源缺包失败：进入市场备用流程
    └─ 取消、等待脚本授权、已进入应用阶段或结果未知：保留当前结果
                         ↓
             查验并尝试可用 npm 注册表、作者 scoped 包、
             已添加安装源中的归档与 GitHub 目标
                         ↓
             成功即停止；全部失败则保留各源诊断
```

- 官方优先阶段直接交给宿主查验，不先查询市场的 GitHub API。市场 API 限流不必然阻断这条路径。
- 市场备用流程优先 npm，逐个核对包名、指定版本及仓库。也会查找作者命名空间下的包，例如 `plugin` 对应的 `@owner/plugin`，拒绝仓库不匹配的同名包。
- 官方已解析的 npm 版本保持固定；GitHub 下载使用已知的完整 commit。未指定 commit 的原生 GitHub 安装使用该仓库默认分支。
- 备用目标未声明兼容范围时，先展示确认面板。脚本授权只针对官方返回的精确名单和原目标，点击允许后才重试。
- 不把长时间无日志、窗口关闭或安装回执丢失当作可自动重试的失败。取消、状态未知或已经开始应用插件时，不启动第二次安装。

详细规则和安装源格式见 [安装源与脚本授权](docs/INSTALLATION-SOURCES.md)。

## 发现插件

- 搜索插件关键词、npm 包名、`owner/repo` 或完整 GitHub 仓库链接，查看介绍、版本、源码与文档。
- 「全部来源」合并 npm、GitHub 和已添加安装源；发现页过滤已安装目标，每页最多 21 项。
- GitHub 关键词搜索限定 `dsh-plugin` topic；指定仓库链接不受 topic 限制。
- 支持 Star、Fork、最近更新与近 7 天 Star 增长排序。周增榜统计匹配范围内总 Star 排名前列的最多 50 个候选，按 GitHub 完整日数据截止昨日计算；它不是全 GitHub 榜单或精确滚动 168 小时统计。
- 查询失败时可展示同查询的成功缓存，并标注缓存信息。搜索中的「候选查验上限」表示本轮扫描预算已用完，可缩小关键词；它不等于安装失败。
- 切换页面后搜索词和筛选恢复默认，避免把上一次查询误当作当前结果。

## 日志、更新与卸载

**安装日志**显示当前阶段、安装源尝试、耗时和最后活动时间。超过 60 秒无活动会提示检查日志或取消，不自行判定安装失败。完成或失败后保留诊断；日志脱敏并限制保留长度，源尝试次数不表示下载百分比。

**已安装**页支持按名称和简介筛选，并通过官方管理器卸载允许移除的插件。**可更新**页区分「发现新版」和「当前可升级」，可查验确切版本。

宿主允许直接升级时使用官方覆盖安装；否则，仅对可安全恢复、能保留加载顺序的目标提供确认后的卸载重装。重装前校验新版与旧版恢复包、备份配置，新版失败会尝试恢复旧版；恢复失败后保留记录并停止继续变更。普通升级失败不会自动改为卸载重装。

市场自身、官方组件、普通本地链接、Git 来源及无法保持加载顺序的目标可能需要手动升级。运行中的宿主也可能禁止覆盖依赖，应按提示完全退出后使用与该宿主匹配的官方方式更新。

## 自定义安装源与备份

页面底部提供「安装源」和「配置备份」。

- **安装源**：导入 JSON，或添加返回 JSON 的 HTTPS 地址并手动更新。目录记录固定 commit、下载地址和归档哈希；镜像须提供校验信息，没有默认第三方 GitHub 镜像。详情中的「加入安装源并缓存」可保存已核对的仓库归档。
- **缓存**：已有归档可复用，安装前仍校验内容。搜索记录本身不足以授权缓存安装；依赖未缓存时仍需网络，不提供离线升级。
- **配置备份**：原始配置仅保存在当前 Profile 的 `.lumen-market/backups/`；导出的 JSON 仅含插件清单与状态。恢复目前是只读差异预览，不自动覆盖配置或安装插件。
- **重装记录**：`.lumen-market/reinstall/` 保存恢复包与来源记录，相关安装仍在使用时请保留。

参见 [安装源格式](docs/INSTALLATION-SOURCES.md)、[配置备份说明](docs/BACKUPS.md)。

## 兼容性与验证范围

市场备用流程根据插件声明检查 DSH、Node.js 及相关范围，区分匹配、冲突、未声明和格式错误；未声明不会被显示为已兼容。官方优先和原生窗口路径的安装判断由 Harness 负责。

0.8.0 发布验证包括项目测试、语法与包入口检查、官方安装接口契约核对、浏览器离线交互和窄屏检查。官方 Web Profile 的打包安装、启动与卸载结果见 [隔离验收记录](docs/STORE-VALIDATION.md)。

这些结果不代表所有宿主版本、操作系统或第三方插件都已验证。浏览器预览使用模拟数据；真实 npm 的 scoped 包查询仅验证目标识别，不等于安装运行该第三方插件。桌面个人 Profile、真实第三方安装及复杂网络中断需分别验证。

## 权限与反馈

插件读取当前 Profile、写入本地缓存与备份，并访问 npm、GitHub 和主动添加的源。安装、更新、卸载及脚本授权均调用官方管理器；哈希和格式校验不等于代码可信。

反馈时可提供宿主版本、市场版本、插件地址、失败阶段和脱敏日志。请勿提交 Token、Cookie、验证码、API Key 或原始私有配置。
