# Profile 配置备份与恢复预览

从市场页底部打开「配置备份」，点击「创建本机备份」。备份只针对当前 Profile，不扫描其他配置或用户文档，也不调用模型。

## 本机保留什么

快照位于当前 Profile 的 `.lumen-market/backups/<ID>/`：

- `files/` 保存存在的 `package.json`、`pnpm-lock.yaml`、`cordis.patch.yml`、`cordis.yml`、`pnpm-workspace.yaml`，原始字节不改写。
- `index.json` 记录文件 SHA-256、插件清单、版本、来源、启用状态和 Bundle 顺序。
- 完成复制并重新检查源文件、完整依赖集合与 specifier 后才发布快照索引；未完成的快照不显示为有效备份。不会批量删除备份。

原配置可能包含私有设置。快照保留在本机，不上传到 GitHub、云端或外部服务；不是加密保险库，Windows 访问权限仍受父目录 ACL 影响。备份不包括 `.npmrc`、独立凭据存储、外部 Patch、node_modules 或插件私有数据库。

## 导出与恢复预览

「导出插件清单」生成可保存的 JSON，只包含经校验的包名、确切版本、来源、启用状态与顺序。npm 目标使用确切版本，GitHub 目标只导出固定 commit；普通本地文件显示需人工核对，不导出机器路径。原始配置正文、Token 和文件内容哈希不进入便携清单。

可以预览本机快照，也可选择导出的 JSON 文件查看差异：

- 本机缺少、版本不同、来源或固定目标不同的插件。
- 启用状态、加载顺序和宿主版本差异；未记录具体位置的本地来源需人工核对。
- 本机快照还能比较配置文件是否变化，预览前会验证快照文件完整性。
- 本机新增插件列在「保持不变」，不会自动删除；预览不会安装插件、写回配置或执行导入文件里的内容。

便携 JSON 不包含配置正文，因此不能代替本机私有配置快照。本轮仅提供只读恢复预览；尚未实现自动应用整套配置、跨 Profile 安装或云同步。

## 接口与限制

- `GET /api/lumen-market/backups`：最多返回 20 个有效快照的摘要。
- `POST /backup`（空对象）：创建本机快照。
- `POST /backup-export`（backupId）：导出便携清单。
- `POST /backup-preview`（backupId 或 backup 二选一）：只读比较。

以上路径均在 `/api/lumen-market` 下，要求自定义 CSRF 头和回环地址；有 Origin 时必须与请求 Host 一致。不存在任意路径读取、覆盖恢复或删除接口。单个配置文件最多 16 MiB，导入 JSON 最多 512 KiB，清单最多 500 个插件。
