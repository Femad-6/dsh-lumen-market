# 安装源与脚本授权

0.8.0 支持 JSON 安装源，保存固定 commit 和实际安装包。安装仍由 DSH 官方管理器处理。

## 通过官方安装

在 Harness 官方「插件」页面选择「流明市场」标签，在卡片或详情点击「通过官方安装」。市场把对应 npm 包名及版本、或 GitHub 地址交给 Harness 原生安装窗口；已取得完整 commit 时保持固定。尚未经过市场查验的 GitHub 条目可直接交给官方，不依赖市场的 GitHub API 额度。

原生窗口自行查验并显示进度、日志、取消及脚本授权；其判断和最终安装结果以宿主为准。该入口不会调用市场的安装预览、自动换源或安装执行接口。独立侧栏入口已移除，统一从官方「插件 → 流明市场」访问；原有一键安装仍在页面内。此入口需要宿主支持 `plugins.tab` 扩展。

## 一键安装自动换源

一键安装先由官方接口查验 GitHub 地址或 npm 包并安装，显示官方日志和进度，支持取消。此阶段不先查询市场的 GitHub API。成功后结束；只有明确未改变配置的网络、超时或源缺包失败才自动进入下述市场换源流程。官方拒绝安装策略、等待脚本授权、用户取消、进入应用阶段、回执丢失或状态未知时不自动重装。官方已解析的 npm 版本及已知 GitHub commit 保持固定；备用目标需额外兼容性确认时，先展示确认面板。

进入市场备用流程后，默认先尝试 npm，即使插件来自 GitHub 列表。核对 npm 包的仓库、包名及指定版本后，优先使用提供该清单的注册表安装；连接失败、超时或该源缺少版本时，继续尝试宿主配置的备用注册表。npm 不可用时，继续尝试已添加目录中的固定归档和 GitHub。目录内的多个下载地址仍按顺序校验与回退。

查询 npm 时先尝试已知包名，再尝试仓库作者命名空间下的包名和仓库名，例如 `plugin` 与 `@owner/plugin`。每个候选都必须核对 npm 清单中的包名、确切版本及仓库归属；第三方同名包不会被接受。安装执行阶段仍保留这些 npm 候选，以便下载失败后继续换源。

跨源切换保持确切版本，允许已核对同仓库、同基础包名的裸名与作者 scoped 名互为来源。已安装同仓库的另一种包名时阻止重复安装。无法确认对应 npm 包时继续使用原仓库，不凭同名包替换。详情、安装预览和安装执行均支持回退；GitHub API 限流不会阻断其他已经可用的安装路径。所有候选都失败时，显示各源失败记录；成功即停止尝试。

注册表地址来自宿主配置和已验证清单，不修改全局设置。脚本授权、取消及应用结果继续由官方管理器处理；已改变配置、进入应用阶段或无法确认结果的安装不自动重试，脚本授权只针对原目标。

## 使用

1. 页面底部打开「安装源」。可选择 JSON 文件、粘贴 JSON 导入，或输入直接返回 JSON 的 HTTPS 地址。已添加的源地址会显示在面板中，点击「重新检查」更新该地址。
2. 发现页的来源选择「已添加的安装源」可单独查看；「全部来源」也包含源目录。完整仓库链接或 owner/repo 不额外查询 npm。
3. 点击「查看详情」或「一键安装」，下载并校验固定版本；未声明兼容性的包仍需确认。
4. 已通过 GitHub 查验的仓库，可从详情点击「加入安装源并缓存」。按钮会下载固定 commit 归档，核对包身份及入口文件，保存 SHA-512，再加入目录。仅查到仓库名称不足以授权安装。
5. 普通新装被脚本许可拦下时，显示「等待安装脚本授权」及官方返回的精确名单。只有点击「允许这些脚本并重试」才提交许可；原目标保持固定。许可记录在当前 Profile。

导入与更新按仓库名称合并，同仓库新条目替换旧条目，未出现的仓库保留。更新源不自动安装插件。新 commit 需源维护者更新 JSON；缓存已有条目继续使用其固定版本，不静默切换到分支最新版本。

## JSON 格式

可直接导入 [sources.example.json](sources.example.json)。示例记录 2026-10-29 下载验证过的 `YuJunZhiXue/dsh-purge` 1.1.82、完整 commit 和归档哈希；已检查实际归档和断网缓存复用，没有安装或运行该插件。

条目字段：`repo`、40 位小写十六进制 `sha`、包名 `name`、确切版本 `version`、`downloads` 数组。下载项字段：HTTPS `url`、`sha512-` 加 Base64 的 `integrity`。

- 同一条目最多 5 个下载地址，按顺序尝试。镜像必须提供同一已确认归档的 SHA-512；失败、损坏或不匹配时尝试下一地址。没有默认第三方镜像。
- 标准固定地址 `https://codeload.github.com/owner/repo/tar.gz/<40位sha>` 可首次省略哈希，仅对此官方地址允许首次学习。其他地址必须提供哈希。
- 最多 200 个仓库、10 个源地址；JSON 上限 512 KiB。源地址仅主动更新，不后台轮询。导出不含本机包路径。
- 地址不接受凭据、查询参数、HTTP、IP / 本机域名和跳转。镜像须使用直接下载的公开 HTTPS 地址。

校验包名、确切版本、DSH bundle 声明、入口 / exports / patch 文件；拒绝路径穿越、链接、重复文件和不支持的 tar 结构。归档上限 64 MiB，解压读取上限 128 MiB，仅在内存读取，不提取文件。JSON 限时 15 秒，归档限时 120 秒。

## 存储与边界

目录保存在当前 Profile 的 `.lumen-market/sources.json`，包保存在 `.lumen-market/archives/`。安装前重验哈希及内容，预览绑定归档哈希；内容变化需重新预览。旧归档保留，不自动删除。本机包安装后记录 GitHub 来源，避免重复显示为未安装。

实际包缓存可避免重复下载 GitHub 归档；依赖未缓存时仍需 npm 网络，脚本仍需许可，运行结果仍由宿主决定。哈希与格式校验不表示代码可信，只添加信任的源。

授权重试覆盖普通新装及直接安装管线；「先卸载再安装」的升级事务遇脚本拦截时仍走原恢复流程，暂未增加事务内授权。上述自动跨源回退用于新装，升级事务保持既有恢复流程。
